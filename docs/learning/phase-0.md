# Phase 0 recap: setup and recon

## What exists now
- A Cargo workspace with four crates: `sim-core` (pure logic, wasm-safe), `sim-protocol`
  (wire types), `sim-server` (axum server and the `simagent` binary), `sim-render` (placeholder for wgpu).
- Shared versions and lints in the root `Cargo.toml`: `unsafe` forbidden, docs required,
  clippy pedantic on, unwrap/expect/println flagged. Tests may unwrap (`clippy.toml`).
- `just check`, the definition-of-done gate: fmt, clippy `-D warnings`, nextest, rustdoc
  `-D warnings`, a wasm32 build of sim-core, and a check that every architecture diagram
  matches its `.drawio` copy. CI runs the same command.
- `bacon.toml` for a live clippy loop, `rust-toolchain.toml` pinning stable plus wasm32.
- Project skills `rust-engineer` and `coding-guidelines`, and `CLAUDE.md` with the working rules.
- Docs: ADR-0001 (overall architecture), `00-overview.md` with the system diagram,
  `visual-identity.md` (our design tokens), and `inspiration-notes.md` (lessons, not a port).

## Rust ideas introduced
- **Workspace vs package vs crate**, and why sim-server is a lib plus a thin bin.
- **Newtype ids** (`SessionId`): a zero-cost wrapper so ids of different kinds can't be mixed.
- **`#[serde(transparent)]`**: the wrapper serializes as the bare inner value.
- **`impl Into<String>`** arguments: callers pass `&str` or `String`; we allocate only once.
- **`#[must_use]`**: the compiler warns if a caller ignores a returned value.
- **`anyhow::Context`** in the binary: errors carry "what we were doing" up to `main`.
- **`#[tokio::main]` / `#[tokio::test]`**: macros that build an async runtime around a function.

## Decisions
- Standalone, original project; no code copied from elsewhere.
- Loopback-only server on port 7410 by default.
- The overview diagram is generated by `scripts/drawio.py` so doc and `.drawio` copies cannot drift.
